# Pathfinder II local dashboard

The dashboard defaults to its standalone simulated flight. Use **Fly it**,
the slider, or phase buttons to inspect the demo. Arming and saved-flight
replay are mockup controls; they do not control or load a real vehicle.

## View the simulated radio flight

Flash the mock-flight sender and receiver as described in
[FEATHER.md](../FEATHER.md), connect the receiver to your laptop, and power
the sender. Close the Arduino serial monitor or `screen`: only one program
can open the serial port at a time.

From the repository root, start the static server:

```sh
python3 -m http.server 8000 --directory web_dashboard
```

Open <http://localhost:8000> in **Chrome or Edge on desktop**, click
**Connect receiver**, and choose the receiver's USB serial port. Web Serial
requires a secure context; localhost qualifies. The browser may take a
moment to open the port. The receiver starts its radio when the browser
opens the serial connection.

The screen switches to **SIMULATED RADIO** mode. It displays the latest
received `SIM_FLIGHT` values and plots only received altitude/downrange
samples; the path clears when the flight restarts. A warning appears if
no valid packet arrives for five seconds, and the last values remain visible.
Other serial lines and unrelated radio packets are ignored; malformed
`SIM_FLIGHT` lines are reported. On disconnect, select **Disconnect / return
to demo** to close the port and restore the standalone demo.

The data is generated by a fixed simulated flight model on the sender, not
by an IMU, GPS, or a real rocket. The radio packets are not authenticated and
do not have payload CRC enabled; they must never be used for flight safety,
recovery, or control. A sender transmission does not guarantee reception.
To stop the server, press Ctrl+C in its terminal.
